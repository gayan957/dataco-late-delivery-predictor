Quick Start Guide (Mac)
🚀 1. Start PostgreSQL (Docker)
Every time you open your project:
docker start weather-db
If you ever doubt it’s running:
docker ps
2. Check DB is alive
docker exec -it weather-db psql -U postgres -d weather_etl
If you see: --> weather_etl=# --> ✔ You are GOOD. Type \q to exit.
3. Run your schema (ONLY if needed)
But if you reset DB: psql postgresql://postgres:secret@localhost:5432/weather_etl -f sql/schema.sql
🔌 4. If connection fails (MOST COMMON FIX)
Step A: Stop local Postgres --> brew services stop postgresql@16
Step B: Restart Docker DB --> docker restart weather-db
📊 5. Quick DB check command -->lsof -i :5432 (You should ONLY see Docker, not local postgres.)
🧹 6. If everything breaks (RESET mode)
docker stop weather-db
docker rm weather-db
Then recreate:docker run --name weather-db \
 -e POSTGRES_PASSWORD=secret \
-e POSTGRES_DB=weather_etl \
-p 5432:5432 \
-d postgres:16
